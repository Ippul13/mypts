# CV. Permata Teknik Solution

Website Company Profile untuk CV. Permata Teknik Solution - General Supplier and Engineering Service.

### 🚀 Live Demo
**[cvpts.netlify.app](https://cvpts.netlify.app/)**

### 🏢 Tentang Kami
CV. Permata Teknik Solution bergerak di bidang General Supplier and Engineering Service. Kami menyediakan solusi pengadaan barang dan jasa teknik untuk kebutuhan industri, konstruksi, dan perusahaan.

### ✨ Fitur Landing Page
- **Company Profile**: Profil singkat perusahaan
- **Layanan**: Daftar service General Supplier & Engineering 
- **Project Gallery**: Dokumentasi project yang pernah dikerjakan
- **Contact Section**: Tombol direct ke WhatsApp & Email
- **Responsive**: Tampil rapi di HP, tablet, & desktop
- **Fast Loading**: 100% static HTML, deploy di Netlify

### 🛠️ Tech Stack
- HTML5
- Tailwind CSS / Bootstrap / CSS Native
- Vanilla JavaScript
- Deploy: Netlify
